# Padroes da entrega

- Responder e documentar em Portugues.
- Manter a solucao demonstravel sem dependencias externas obrigatorias.
- Usar Node.js nativo com `node:test` para facilitar execucao local e avaliacao.
- Organizar cada microsservico em `domain`, `application`, `infrastructure` e `presentation`.
- Documentar explicitamente Clean Code, SOLID, Design Patterns, TDD, BDD, Docker e Deploy.
- Para deploy, manter `render.yaml` como caminho principal e atualizar o README com os links reais apos publicar.
